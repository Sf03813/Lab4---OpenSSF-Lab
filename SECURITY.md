# Security Policy

## Supported Versions
Currently, the latest commit on the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability:
- Use GitHub's private vulnerability reporting feature on this repository under the **Security** tab, or
- Contact the repository maintainer directly via GitHub profile contact details.

You can expect an acknowledgment within 48 hours and updates as a resolution is developed.
